## 🌟 FLUX.2 [dev] Studio (Official Replica)

```
[ 💡 Prompt + Reference Images ] ➔ [ ✨ Prompt Upsampling ] ➔ [ ⚡ FLUX.2 Transformer ] ➔ [ 🖼️ 4K Photorealistic Output ]
```

1. **Exact Official UI**: Direct replica of the [Hugging Face Space: black-forest-labs/FLUX.2-dev](https://huggingface.co/spaces/black-forest-labs/FLUX.2-dev).
2. **Multi-Image Reference**: Upload up to 3 images for character, style, and object consistency.
3. **Advanced Settings**:
   - **Prompt Upsampling**: Automatically rewrites simple prompts into detailed visual prompts.
   - **Width & Height**: 256 to 1024 px.
   - **Guidance Scale**: 0.0 to 10.0 (default 4.0).
   - **Inference Steps**: 1 to 100 steps (default 30).
   - **Seed Control**: Fixed seed or randomize.
4. **Auto-Save**: Saves directly to `/MyDrive/FLUX2_Images/` in your Google Drive.
