## 🎬 AI YouTube Video Creator (Zero API Keys)

```
[ 💡 Topic: "5 Facts About Space" ] ➔ [ 📝 Script ] ➔ [ 🎙️ Hindi/English Voice ] ➔ [ 🎨 4K Visuals + Motion ] ➔ [ 🎬 1080p MP4 ]
```

1. **Video Subject**: Enter any topic (e.g., *"5 Facts About the Ocean"*).
2. **Voice & Language**: Hindi (`Madhur` / `Swara`), English (`Deep Narrator`), Bengali, Urdu.
3. **Aspect Ratio**: `9:16` (Shorts / Reels / TikTok) or `16:9` (Standard YouTube).
4. **Subtitles**: High-contrast Yellow/White viral captions.
